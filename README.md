# gitex1

Git と GitHub の基本操作、および Java プログラムの実行を練習するためのリポジトリです。

## プロジェクト概要

Eclipse の Java プロジェクト名は `project1` です。

| ファイル | 内容 |
| --- | --- |
| `src/project1/Hello.java` | `Hello` と表示します |
| `src/project1/HelloWorld.java` | `HelloWorld` と表示します |

## 実行方法

Eclipse でこのリポジトリを Java プロジェクトとして開き、実行するクラスを選びます。

```java
System.out.println("HelloWorld");
```

## Git の練習内容

- 変更したファイルをコミットする
- `test` ブランチで変更を行う
- `main` ブランチに戻って別の変更を行う
- ブランチ間の変更とコミット履歴を確認する
- README の Markdown 表記を確認する
